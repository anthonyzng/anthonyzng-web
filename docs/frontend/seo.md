# Frontend: SEO

Moved from `CLAUDE.md` section 6.1.

- **SEO** (Phase 8): `index.html` holds what every page shares, for crawlers that run no script: the description, `theme-color` per colour scheme, `hreflang` alternates (`en` → `/en`, `zh-Hant` → `/zh-hant`, `x-default` → `/en`), Open Graph (`og:type`, `og:site_name`, `og:image` = `/og-image.png`, 1200×630, drawn by `frontend/scripts/og-image.py` with the site's fonts and palette; run it with the backend's Python) and `twitter:card`, and JSON-LD structured data (a `Person` with the three roles and the approved LinkedIn / GitHub links; a data block, never executed, so the CSP needs nothing for it). `DocumentMeta` (`src/components/DocumentMeta.tsx`, helpers in `src/seo.ts`) sets the language-specific parts in a layout effect: title, `meta.description` (both locales), the canonical URL, `og:title`, `og:description`, `og:url`, `og:locale` (`en_US` / `zh_HK`); canonical and Open Graph URLs are absolute on `SITE_ORIGIN` (`https://owwsolution.com`) whatever host serves the page. There is no static canonical (it would name `/en` on the Chinese page before the script runs). `public/robots.txt` allows everything but `/admin` and names `public/sitemap.xml` (both home pages, each with its alternates). The SPA answers unknown paths with 200, so `NotFoundPage` adds `<meta name="robots" content="noindex">` while mounted (no soft 404 in the index); the admin panel sends its own `noindex`. Lighthouse (production build): accessibility, SEO and best practices 100 in both languages. The ghost numerals are generated content (`data-numeral` + `::before`), decorative and never counted as low-contrast text; each theme draws its own (`formatGhostNumeral`, `sectionIds.ts`): formal Chinese numerals in light mode (壹 貳 參 肆, Yuji Mai), Roman numerals in dark mode (I II III IV, Cinzel Decorative, tightened and held in from the right edge the desktop drift carries them to), while the counter beside each title keeps "01 / 04". Performance: desktop about 97; Lighthouse's throttled mobile profile about 72–78, bounded by the scroll-driven design (the first commit runs every `useGSAP` setup and the first full layout in one task, and the hero name's mask reveal delays LCP by the intro): measured, accepted as the cost of the non-negotiable motion; Cloudflare's CDN serves the assets.
